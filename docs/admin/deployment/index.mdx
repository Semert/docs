# Deployment Guides

Welcome to the AI/Run CodeMie deployment guides. A full deployment follows four phases: provision infrastructure, deploy the platform, configure your installation, then maintain and secure it.

## Infrastructure Deployment

Provision the cloud infrastructure required to run CodeMie — Kubernetes clusters or virtual machines, networking, storage, and databases — using Terraform. Supports AWS, GCP, and Azure.
